<img width="1917" height="877" alt="image" src="https://github.com/user-attachments/assets/447df6d4-a4db-4d49-8021-ecb6f3bfa47e" /># 🎨 MyCraftopia

A full-stack Art & Craft e-commerce and learning platform where users
can explore creative classes, shop for craft products, manage their
cart, and place orders.

## 🚀 Live Demo

Frontend: https://mycraftopia-delta.vercel.app/
Backend API: https://mycraftopia-backend-deploy.onrender.com

## ✨ Features

- 🏠 Interactive home page
- 🎨 Art & craft classes
- 🛍️ Product marketplace
- 🔎 Product search and filtering
- 📦 Product details
- 🛒 Shopping cart
- 🔐 User registration and login
- 📍 Delivery address management
- 💳 Payment method selection
- 📦 Order placement
- 📋 My Orders
- 📱 Responsive UI

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS
- React Router
- Axios
- Swiper.js

### Backend
- Python
- Flask
- Flask-SQLAlchemy
- Flask-CORS
- REST API
- Gunicorn

### Database
- SQLite (development)
- PostgreSQL (production)

### Deployment
- Vercel – Frontend
- Render – Backend
- Cloudinary – Image Management

## ⚙️ Installation

### Clone Repository

git clone https://github.com/AyushiVispute/MyCraftopia.git

cd MyCraftopia

### Frontend

cd frontend
npm install
npm run dev

### Backend

cd backend
python -m venv venv

# Windows
venv\Scripts\activate

pip install -r requirements.txt

python app.py

## 🔐 Environment Variables

### Frontend

VITE_API_URL=your_backend_url
